# Supplied resources: local placement

The assignment's large inputs and evaluation files are **local resources**, not Git submissions. The repository currently tracks placeholder directories; `.gitignore` excludes the corpus, datasets, generated index and output. Place the resources as follows before running the project:

| Supplied resource | Local destination | Notes |
| --- | --- | --- |
| vLLM 0.10.1 repository | `data/raw/vllm-0.10.1/` | Keep the directory name and its prefix. Search results must use paths such as `data/raw/vllm-0.10.1/docs/...`. If supplied as an archive, extract it here without an extra nested directory. |
| Unanswered question JSON datasets | `data/datasets/UnansweredQuestions/` | Keep each supplied dataset filename. |
| Answered question JSON datasets | `data/datasets/AnsweredQuestions/` | These are the ground truth for local evaluation. |
| `moulinette-ubuntu` / `moulinette-fedora` | Local project root, renamed to `moulinette` when used | Choose the executable for the machine. Use it only for manual evaluation; the application must not import or call it. Do not commit the binary. |
| Assignment PDF | `docs/subject.pdf` (optional local copy) | The source PDF is ignored by Git; the English and French Markdown adaptations are tracked in `docs/`. |
| Generated index | `data/processed/` | Created by `index`; do not copy it from the attachments or commit it. |
| Generated search and answer JSON | `data/output/search_results/<DatasetScope>/` and `data/output/search_results_and_answer/<DatasetScope>/` | Generated by the CLI; use a separate scope for `UnansweredQuestions` and `AnsweredQuestions`. |

The **GitHub branch does not currently contain the supplied vLLM corpus or question datasets**. This is consistent with the subject's instruction not to submit large data or generated output. If they have been copied into the local checkout, `.gitignore` intentionally keeps them out of `git status` and GitHub. Check the local directory layout directly; an empty `.gitkeep` in GitHub does not establish that the resource exists on your machine.

Do not commit model weights, the deep-learning cache, data archives, or generated results. The evaluator supplies or generates these resources. `pyproject.toml`, `uv.lock`, the application, Makefile and README must be versioned once implemented.
